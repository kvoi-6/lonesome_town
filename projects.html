Fibonacci Cycle Visualizer

Once a few years ago, while bored in a math lecture, I was listing the fibonacci sequence in the margins of my notebook. But I didn't want to spent time on adding large numbers, so I decided to only write the last digits, as while only caring about the last digit of future numbers only the last digit of previous numbers is needed. And I realized that since there are limited pairs of last digits these digits would eventually repeat in cycles.

Anyways, I ended up making this visualizer for this. The X and Y axis each represent one of the two numbers' final digits, with a darker color indicating smaller numbers. While hovering over a tile, that tile's full cycle is shown with a circle proceeding through the cycle to help indicate how it progresses.

There is also a slider to change the base of the number system being used. Something interesting about this is that within one number system, the cycles from the systems with bases that are factors of the current system's base will still be present, but will be upscaled to the new base. For example, base 2's triangle cycle is present in all even bases and base 5's tilted square cycle is present in all bases that are multiples of 5.

As far as I know this has no practical applications
